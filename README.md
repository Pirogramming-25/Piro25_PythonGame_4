## 🌸 두부게임

### 🎮 게임 소개
두부두부게임은 현재 기준이 되는 사람이 항상 **두부 3모**가 되고, 그 사람을 기준으로 주변 사람들의 두부 모 수가 계속 바뀌는 순발력 술게임입니다.  
플레이어는 현재 기준자를 중심으로 누가 몇 모인지 빠르게 판단해야 하며, 잘못 말하거나 제한 시간 안에 대답하지 못하면 벌칙으로 술 1잔을 마시게 됩니다.

### 📜 게임 규칙
1. 현재 차례인 사람은 항상 **두부 3모**입니다.
2. 현재 3모를 기준으로 왼쪽 두 번째 사람은 **1모**, 왼쪽 첫 번째 사람은 **2모**입니다.
3. 현재 3모를 기준으로 오른쪽 첫 번째 사람은 **4모**, 오른쪽 두 번째 사람은 **5모**입니다.
4. 현재 3모가 “두부 N모”를 외치면, 해당 N모 위치의 사람이 새로운 3모가 됩니다.
5. 자기 자신인 **두부 3모**를 외치면 벌칙을 받습니다.
6. 로그인한 사용자는 제한 시간 안에 1~5 중 하나를 입력해야 합니다.
7. 제한 시간 안에 입력하지 못하거나, 1~5가 아닌 값을 입력하면 벌칙을 받습니다.
8. 컴퓨터 플레이어는 랜덤으로 두부 모 수를 외치며, 일정 확률로 박자를 놓쳐 벌칙을 받을 수 있습니다.
9. 누군가 벌칙을 받아 술 1잔을 마시면 두부게임 한 판이 종료되고, 메인 게임 화면으로 돌아갑니다.

### ✨ 주요 기능
- 현재 참여자 기준으로 자리 순서를 랜덤 배치합니다.
- 현재 3모를 기준으로 1모, 2모, 4모, 5모를 자동 계산합니다.
- 사용자의 차례일 때만 직접 입력을 받습니다.
- 사용자가 제한 시간 안에 입력하지 못하면 자동으로 벌칙 처리됩니다.
- 컴퓨터 플레이어는 자동으로 게임을 진행하며, 랜덤 확률로 실수할 수 있습니다.
- 벌칙 결과가 전체 플레이어의 음주 기록에 반영됩니다.
- 참여자가 본인 포함 4명 미만이면 두부게임이 실행되지 않도록 예외처리했습니다.
## 🍦 베스킨라빈스31 게임
### 🎮 게임 소개
베스킨라빈스31은 두 사람이 번갈아 숫자를 부르며 **31을 부르는 사람이 걸리는** 순발력 술게임입니다.  
플레이어는 1부터 시작해 한 번에 1~3개씩 숫자를 이어서 부르고, 마지막 숫자인 31을 외치게 되면 벌칙으로 술 1잔을 마시게 됩니다.
### 📜 게임 규칙
1. 숫자는 **1부터 시작**하며, 두 사람이 번갈아가며 외칩니다.
2. 한 번의 차례에 **최소 1개, 최대 3개**의 숫자를 이어서 부를 수 있습니다.
3. 반드시 직전 사람이 부른 숫자의 **다음 숫자부터 연속**으로 불러야 합니다.
4. 마지막 숫자인 **31을 외친 사람**이 벌칙을 받습니다.
5. 로그인한 사용자는 자기 차례에 부를 숫자를 직접 입력해야 합니다.
6. 숫자가 아니거나, 연속되지 않거나, 1~3개 범위를 벗어난 입력은 다시 받습니다.
7. 컴퓨터 플레이어는 랜덤으로 1~3개의 숫자를 이어서 외칩니다.
8. 누군가 31을 외쳐 술 1잔을 마시면 베스킨라빈스31 한 판이 종료되고, 메인 게임 화면으로 돌아갑니다.
### ✨ 주요 기능
- 나 vs 컴퓨터로 진행되며, 차례가 자동으로 번갈아 넘어갑니다.
- 현재까지 불린 숫자를 기준으로 다음에 부를 수 있는 숫자 범위를 자동 계산합니다.
- 사용자의 차례일 때만 직접 입력을 받습니다.
- 잘못된 입력(숫자 아님 / 연속 아님 / 개수 초과)에 대해 예외처리하여 다시 입력받습니다.
- 컴퓨터 플레이어는 자동으로 1~3개의 숫자를 이어서 외칩니다.
- 31을 부른 사람(패자)의 이름을 반환하여 메인 게임에서 음주 기록에 반영할 수 있습니다.
# 👀 눈치게임

### 🎮 게임 소개

1~5 중 하나의 숫자를 선택하여 가상 참가자들과 숫자가 겹치지 않도록 하는 눈치게임입니다.
파이썬의 랜덤 기능을 활용하여 혼자서도 눈치게임을 즐길 수 있습니다.

### 📌 게임 규칙

1. 컴퓨터 참가자 수를 1~4명 중에서 설정합니다.
2. 1~5 중 하나의 숫자를 선택합니다.
3. 다른 참가자와 숫자가 겹치면 술 1잔이 누적됩니다.
4. 숫자가 겹치지 않으면 성공입니다.

### 💻 주요 기능

- 참가자 수 설정, 랜덤 숫자 선택, 숫자 중복 여부 확인
- 라운드별 술잔 수 누적 및 게임 종료 시 최종 결과 출력

## 실행 방법

python nunchi_game.py
